# welltest_examples
Учебные материалы по гидродинамическим исследованиям скважин для курсов в РГУ нефти и газа имени И.М.Губкина
Примеры расчетов для простых нестационарных моделей работы скважин с использованием Jupyter Notebook и Python.

Для запуска можно использовать Google Colab - там можно указать данные репозиторий и открыть любой ноутбук.

Раньше можно было использовать mybinder нажав кнопку ниже

# Структура папок в репозитории

- book - материалы подготовленные для книги
- welltestpy - модули python для проведения расчетов
- examples - блокноты и расчетные модули с примерами проведения расчетов
    - basic - блокноты и расчеты не зависящие от welltestpy
    - notebooks - блокноты, которые зависят от welltestpy
    - notebooks_interactive - интерактивные блокноты и примеры мини приложений
    - sandbox -  песочница - экспериментальные блокноты и расчетные модули
    - python - приложения в виде python файлов
- data - файлы с полезными данными которые могут быть многократно использованы в разных расчетах
- models - модели для различных программ
